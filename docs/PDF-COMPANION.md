# PDF companion

The canonical paper is [4DM-WP-1.0.md](4DM-WP-1.0.md).

A typeset PDF companion can be generated locally:

```bash
python3 tools/build_whitepaper.py
```

That writes `docs/4DM-WP-1.0.pdf` when a PDF writer is available.

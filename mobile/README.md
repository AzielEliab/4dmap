# 4DMap — iPhone & Android

Inspection coordinate frame. This phone app is a kid-plain shell.
Full engine is the desktop package.

Offline. No analytics. Dark matte / gold.

Application id: `com.azieeliab.fourdmap`

Not a truth engine. Not a store listing. Not a separate repo. Not store IPAs.

## Open in Android Studio / Xcode

The `android/` and `ios/` folders here are skeleton READMEs because
this tree was written without the Flutter SDK on PATH.

```bash
cd mobile
flutter create --org com.azieeliab --project-name fourdmap .
flutter pub get
flutter run
```

## Honest scope

THIS IS an inspection coordinate frame (4DM-WP-1.0).
THIS IS NOT a truth engine, Lumen, GIS 4D, or a Node Gate.
